# ct1-week2-html-css-basics
Technical workshop introducing HTML and CSS

In today's workshop we will be covering the basics of HTML and CSS.

### Repository Information
In this repository you'll find 4 files:
- This README document
- 1 HTML file
- 2 CSS files

The README is the document you're reading now. You can use a README as a guide for each workshop.

The HTML file is laid out as a basic "about me" page for a portfolio. It has a small blurb about the author, some example contact information, and some other elements like headings.

The CSS files contain 2 different approaches to styling this "about me" page. We'll be looking at how the differences change the focus of the site in terms of audience, and messaging.

### Today's Goal
Today I'll be introducing the basics of HTML and CSS, what they are used for, and how they work together to create a web page.
